# BlazorApp

This is a Blazor WebAssembly app scaffolded with `dotnet new blazorwasm`.

Run locally:

```bash
cd Proiect-PSI/BlazorApp
dotnet restore
dotnet build
dotnet run
```

Open the browser at the address shown by `dotnet run` (usually https://localhost:7041 or similar).

Notes:
- Targets .NET 10.0.
- Project created on macOS using the `dotnet` CLI.
